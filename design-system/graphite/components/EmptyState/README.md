# EmptyState

The content shown when there is no data yet: what this is, why it is empty, and the next step.

- Gồm tiêu đề ngắn, một câu giải thích và tối đa một hành động chính.
- Icon tuỳ chọn, đặt trong vòng tròn `layer-extension`. Không dùng hình minh hoạ lớn.
- `sm` dùng trong card hoặc cột hẹp (Messages, Communications).
