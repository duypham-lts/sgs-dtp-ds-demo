# Separator

Đường kẻ ngăn 1px `border-subtle-00`, ngang hoặc dọc.

- UI Guidelines ưu tiên **không dùng viền**, nên chỉ dùng Separator khi lớp nền không đủ để phân tách: giữa các nhóm trong menu, giữa các mục trên page header (title · status · autosave).
- `decorative` khi đường kẻ chỉ để trang trí (`role="none"`).
- Radix: `Separator.Root`.
