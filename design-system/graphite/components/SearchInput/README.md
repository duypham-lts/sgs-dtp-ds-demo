# SearchInput

A search field with a magnifying-glass icon; the label is visually hidden by default but still read by a screen reader.

- Dùng `showLabel` khi ô tìm kiếm là một bộ lọc nằm trong form.
- Trên màn Homepage, vùng search chiếm 66% bắt đầu ở 905px và dừng ở 1005px; các CTA bên cạnh được giãn nhưng search thì không (UI Guidelines, Homepage).
