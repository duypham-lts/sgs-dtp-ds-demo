# Breadcrumb

Shows where the page sits in the navigation tree; parent levels are orange Links, and the current page is medium-weight `text-primary` text that is not clickable.

- Theo bảng spacing: cách subheader phía dưới `spacing-05` 32px.
- **Cần xác nhận:** trong mockup AI settings, các cấp trên màu tối và trang hiện tại màu cam, ngược với quy tắc link cam của UI Guidelines. Bản này đang theo UI Guidelines.
