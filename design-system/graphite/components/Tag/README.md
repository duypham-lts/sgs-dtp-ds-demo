# Tag

A short one- or two-word label for classification, with no status meaning; to show status, use StatusTag.

| Tone | Dùng cho |
|---|---|
| `neutral` | Framework, loại dịch vụ, metadata |
| `required` | Đánh dấu phần bắt buộc, ví dụ "Required" trên card Buyer |
| `info` | "Optional", gợi ý trung tính |

**Giả định:** nền `tag-warning-bg` và `tag-info-bg` lấy từ Carbon Yellow 10 và Blue 10, chưa có trong Figma.
