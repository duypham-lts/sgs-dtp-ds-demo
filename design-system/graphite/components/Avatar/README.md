# Avatar

A user's photo or initials; used in the top bar (Profile menu), comments, and the assignee.

- Cỡ `sm` 24, `md` 32 (mặc định), `lg` 40. Nền `brand-charcoal`, chữ trắng.
- Chữ viết tắt lấy chữ cái đầu của tên đầu và tên cuối. Không có tên thì hiện icon người dùng.
- Radix: `Avatar.Root`, `Avatar.Image`, `Avatar.Fallback`.
